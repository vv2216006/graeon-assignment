What I built
- ocr.py: reads each video with OpenCV (2 frames per second), runs EasyOCR on
  each frame, and stores the results in SQLite (results.db).
- app.py: Flask page that shows the OCR results, a "most frequent readings"
  table, and a button to download an Excel report (All readings + Summary sheets).

How to run
1. pip install -r requirements.txt
2. python ocr.py      (wait for "Done")
3. python app.py      then open http://127.0.0.1:5000

What the videos show
Handheld clips of steel bars with numbers written on them in chalk
(for example B/02535). Both videos are processed and the video name is stored.

Issues / limitations
- Chalk on rough steel plus camera motion makes OCR noisy. Many readings are
  partial or wrong (for example 0525 instead of 02535).
- My first attempt used contrast enhancement and a digits-only filter. It gave
  far fewer readings, so I removed it and kept a simple version: confidence
  threshold 0.20 and only keep text containing a digit.
- The second video is blurrier and gives weaker results.
- Runs on CPU only, so the OCR step takes a few minutes.

What I would do next
- Detect and crop the bar surfaces before OCR.
- Combine readings across frames (voting) to get one clean number per bar.
- Try a model trained for handwriting or scene text.
